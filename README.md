# ZYNTRA Store — Backend + Order System

একটা কাজ করা অনলাইন স্টোর: প্রোডাক্ট লিস্টিং, কার্ট, চেকআউট ফর্ম, আর অর্ডার সেভ হয় সার্ভারে।
পেমেন্ট গেটওয়ে নেই — কাস্টমার Cash on Delivery / bKash / Nagad বেছে নেয়, তুমি ম্যানুয়ালি টাকা
চেক করে অ্যাডমিন প্যানেল থেকে অর্ডার কনফার্ম করবে।

## এতে যা আছে
- `server.js` — Express ব্যাকএন্ড (প্রোডাক্ট API, অর্ডার সেভ, অ্যাডমিন API)
- `public/index.html` — কাস্টমারদের দেখা স্টোর
- `public/admin.html` — তোমার অর্ডার ম্যানেজমেন্ট ড্যাশবোর্ড
- `orders.json` — সব অর্ডার এখানে সেভ হয় (ফাইল-বেসড, আলাদা ডেটাবেস লাগে না)

## ধাপ ১ — নিজের কম্পিউটারে টেস্ট করা (ঐচ্ছিক কিন্তু সুপারিশকৃত)

1. [Node.js](https://nodejs.org) ইনস্টল করো (LTS ভার্সন)
2. এই ফোল্ডারে টার্মিনাল খুলে চালাও:
   ```
   npm install
   ```
3. `.env.example` ফাইলটা কপি করে `.env` নামে সেভ করো, তারপর ভেতরে:
   - `ADMIN_KEY` — নিজের একটা লম্বা পাসওয়ার্ড বসাও (এটা দিয়ে তুমি অ্যাডমিন প্যানেলে ঢুকবে)
   - `BKASH_NUMBER` / `NAGAD_NUMBER` — তোমার আসল bKash/Nagad নম্বর বসাও
4. সার্ভার চালাও:
   ```
   npm start
   ```
5. ব্রাউজারে যাও: `http://localhost:3000` — স্টোর দেখাবে
6. অ্যাডমিন প্যানেল: `http://localhost:3000/admin.html` — তোমার `.env`-এ দেওয়া `ADMIN_KEY` দিয়ে ঢুকবে

## ধাপ ২ — ইন্টারনেটে লাইভ করা (ফ্রি হোস্টিং দিয়ে)

GitHub Pages এখানে কাজ করবে না, কারণ এটাতে ব্যাকএন্ড সার্ভার চালানো যায় না। এর বদলে
**Render.com** ব্যবহার করো (ফ্রি টায়ার আছে, সহজ):

1. এই পুরো ফোল্ডারটা একটা GitHub রিপোজিটরিতে আপলোড করো
2. [render.com](https://render.com) এ গিয়ে অ্যাকাউন্ট বানাও, GitHub দিয়ে সাইন-ইন করো
3. "New +" → "Web Service" → তোমার রিপো সিলেক্ট করো
4. Settings:
   - Build Command: `npm install`
   - Start Command: `npm start`
5. "Environment" ট্যাবে গিয়ে `.env`-এর মতো ভ্যারিয়েবলগুলো (ADMIN_KEY, BKASH_NUMBER, NAGAD_NUMBER) যোগ করো
6. Deploy করলে একটা লিংক পাবে (যেমন `https://zyntra-store.onrender.com`) — এটাই তোমার লাইভ সাইট
7. অ্যাডমিন প্যানেল হবে: `https://zyntra-store.onrender.com/admin.html`

> ফ্রি টায়ারে সার্ভার কিছুক্ষণ অব্যবহৃত থাকলে "ঘুমিয়ে" যায়, প্রথম ভিজিটে ২০-৩০ সেকেন্ড দেরি
> হতে পারে। ব্যবসা বড় হলে পেইড প্ল্যানে (মাসে ~$7) আপগ্রেড করলে এটা থাকবে না।

## ধাপ ৩ — নিজের ডোমেইন যোগ করা (ঐচ্ছিক)

Render-এর "Settings → Custom Domain" থেকে নিজের কেনা ডোমেইন (যেমন zyntramarket.com)
যোগ করতে পারবে। ডোমেইন কেনা যায় Namecheap, GoDaddy, বা বাংলাদেশি প্রোভাইডার থেকে।

## প্রোডাক্ট বদলাতে চাইলে

`server.js` ফাইলের ভেতরে `products` অ্যারেটা খুঁজে বের করো — নাম, দাম, ক্যাটাগরি সব এখানেই
বদলানো যায়। সেভ করে সার্ভার রিস্টার্ট করলেই আপডেট হয়ে যাবে।

## অর্ডার কীভাবে কাজ করে

1. কাস্টমার কার্টে প্রোডাক্ট যোগ করে, চেকআউটে নাম/ফোন/ঠিকানা দিয়ে অর্ডার করে
2. অর্ডারটা `orders.json`-এ সেভ হয়, স্ট্যাটাস শুরুতে "pending"
3. তুমি `/admin.html`-এ গিয়ে অর্ডার দেখো — bKash/Nagad হলে টাকা এসেছে কিনা চেক করো
4. স্ট্যাটাস বদলাও: pending → confirmed → shipped → delivered

## ভবিষ্যতে সত্যিকারের পেমেন্ট গেটওয়ে (SSLCommerz) যোগ করতে চাইলে

ট্রেড লাইসেন্স হয়ে গেলে জানিও — SSLCommerz-এর merchant account নিয়ে `server.js`-এ
পেমেন্ট ইনিশিয়েশন রুট যোগ করে দেব, তখন কাস্টমার সরাসরি ওয়েবসাইট থেকেই bKash/Nagad/কার্ড
দিয়ে পে করতে পারবে, ম্যানুয়াল চেক করা লাগবে না।
